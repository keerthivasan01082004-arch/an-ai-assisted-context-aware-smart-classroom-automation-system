💡 Advanced Features & Tips

🔴 Red Highlight Detection

If your timetable uses red color to highlight active classes, the AI will automatically detect and prioritize those regions. This provides visual context awareness similar to human understanding.

✅ Course Code Validation

The system validates all extracted course codes using fuzzy matching. If OCR makes a mistake (e.g., "C5I3616"), it automatically corrects it to the closest valid code ("CSI3616"). View corrections in the Raw OCR Output page.

📄 Extraction Transparency

Click "Raw OCR Output" to see exactly what text was extracted before processing. This shows all preprocessing methods, red region detection, and the complete OCR output for debugging.

📸 Best Practices for Upload

  • Ensure good lighting when taking the photo
  • Keep the timetable flat and avoid shadows
  • Make sure all text is clearly visible
  • Use high resolution images (90-95% accuracy)
  • Red-highlighted cells will be detected automatically
  • System works with different timetable formats
